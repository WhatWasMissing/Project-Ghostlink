Built from a heavily edited blackrock source, ghostlink wouldn't exist without hellomike's work to base.

Project Ghostlink is a real-time memory (RTM) tool for PS3, via [PS3MAPI](https://github.com/aldostools/webMAN-MOD).
## Android app (beta)

Ghostlink now also has an Android app. It connects to the PS3 over your local network using webMAN PS3MAPI. The main cheats work, but the Android app is still in beta, so some features may be incomplete or may not work as expected yet.

The Releases page includes separate ARM32 (`armeabi-v7a`) and ARM64 (`arm64-v8a`) APKs. Choose the build that matches your device; for example the Galaxy A20e uses ARM32 and the Galaxy S22 uses ARM64. The phone and PS3 must be on the same local network, and PS3MAPI must be enabled in webMAN MOD. 


## Requirements

- Grab the latest build from the [Releases](../../releases) page.
- A PS3 running **[webMAN MOD](https://github.com/aldostools/webMAN-MOD)** (CFW required/Hen)
- **PS3MAPI** enabled in webMAN MOD's settings

## Enabling PS3MAPI

1. Install [webMAN MOD](https://github.com/aldostools/webMAN-MOD) on your CFW/Hen PS3, if not already installed.
2. From the XMB, go to webMAN's settings.
3. Enable **PS3MAPI**.
4. Note your PS3's IP address - you'll enter this into the app.
